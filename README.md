# AML Imaging Analysis

This repository contains a Python package for retrieving and analyzing the public `CMB-AML` imaging collection from the Cancer Imaging Archive (TCIA) and for revealing similarity patterns across AML patients.

## Data citation and usage policy

This project uses the Cancer Moonshot Biobank – Acute Myeloid Leukemia (CMB-AML) dataset from The Cancer Imaging Archive (TCIA).

Data citation required:

> Cancer Moonshot Biobank. (2023). Cancer Moonshot Biobank – Acute Myeloid Leukemia (CMB-AML) (Version 9) [dataset]. The Cancer Imaging Archive. https://doi.org/10.7937/pcte-6m66

Acknowledgement:

> Data used in this publication were generated by the National Cancer Institute’s Cancer Moonshot Biobank.

Users must also comply with the TCIA Data Usage Policy and Restrictions: https://www.cancerimagingarchive.net/data-usage-policies-and-restrictions/

## Same-patient AML cohort design

The correct AML-analysis design is patient-centric. Imaging, pathology, and clinical datasets should be aligned by the same patient identifiers and, when available, the same longitudinal visit or timepoint. This avoids mixing unrelated patients across data sources.

The package includes a same-patient merge helper that intersects multiple patient-level tables and keeps only records shared by all provided data sources.

## Goals

- Fetch collection metadata from the TCIA API and save it to the repository.
- Build a patient-level similarity analysis for radiology and pathology metadata.
- Enforce same-patient matching across imaging, pathology, and clinical sources.
- Provide a CLI and reusable package APIs for pattern discovery.
- Keep the project ready for GitHub-based collaboration and iterative analysis.

## Quick start

```bash
python -m pip install -e .
aml-imaging --help
```

## Collection

The project currently targets the public Cancer Moonshot Biobank – Acute Myeloid Leukemia (CMB-AML) collection available on TCIA:

- https://www.cancerimagingarchive.net/collection/cmb-aml/

## Output

Downloaded metadata is stored under `data/` and can be used for patient comparison and clustering.
